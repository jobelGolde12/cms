# Accessibility Report

- Fixed: `jsx-a11y/alt-text` in PDF report images (added alt props)
- Report cards: buttons have accessible names ("View Report")
- Tables: semantic `<table>` with `<thead>` and `<tbody>`
- Focus: keyboard navigable links/buttons
- Contrast: sufficient (brand colors on white)
- No motion-sensitive animations on reports
- Remaining: PDF output accessibility depends on viewer (not web UI)
